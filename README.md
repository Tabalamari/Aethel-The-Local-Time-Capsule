Aethel: The Local Time Capsule 🕰️✨
Aethel is a hyper-local digital time capsule and living archive designed to preserve everyday memories, local stories, and the authentic atmosphere of specific towns and neighborhoods. Instead of gloss and algorithmic feeds, Aethel captures the quiet, genuine moments of daily life for future generations.

🌟 Key Features
The Locked Vault & Timer: A prominent countdown timer on the homepage counting down to the grand opening of the town's time capsule. Content is collected securely until the vault unlocks.

Daily Snapshots: An unglamorous, continuous stream of everyday life (e.g., morning coffee, the view from a window at 8:00 AM) tied to specific calendar dates.

Future Letters: Personal or community messages written to the future (e.g., the year 2050) with a set release date.

Audio-Geotagging (Sound Map): An interactive map of the town featuring "sound points"—ambient noises, local history, and voice memories recorded by residents.

Location-Based Navigation: Cascading dropdowns (Country → City → District) with the ability for users to dynamically add new local areas.

Privacy & Unique Usernames: Quick, frictionless registration allowing users to pick a unique nickname to keep their real identity private while sharing memories.

Direct Messaging & Comments: Public comments on media items and private direct messaging between residents.

🚀 Getting Started
To run this project locally, follow these steps:

Clone the repository:

Bash
git clone https://github.com/your-username/aethel-time-capsule.git
Navigate to the project directory:

Bash
cd aethel-time-capsule
Install dependencies:

Bash
npm install
Set up your environment variables:
Create a .env file in the root directory and add your API keys and database credentials.

Start the development server:

Bash
npm start
💡 Monetization & Concept
Aethel combines community heritage with sustainable micro-monetization, featuring options like "Sponsored Spotlights" for local businesses and community announcements to support the platform.
